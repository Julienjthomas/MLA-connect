## Why

The Malayalam (`app_ml.arb`) strings are incorrect or missing for many user-facing keys, and several strings in both locales still use "report/reports" terminology where the app has standardised on "issue". This causes inconsistent and inaccurate UI text for Malayalam-speaking users.

## What Changes

- Correct existing Malayalam strings that have wrong translations (e.g., `panchayatHelp`, `basicProfile`, `basicProfileSubtitle`, `notificationSubtitle`, `issueUpdates`, `issueUpdatesDesc`, `emergencyAlerts`, `emergencyAlertsDesc`, `eventReminders`, `allSetSubtitle`, `goToHome`, `quickActions`, `quickActionSuggest`, `quickActionSuggestSubtitle`, `contactOffice`, `messageMla`, `communityBannerHeadline`, `communityBannerSubtext`, `reportSuccessMsg`, `trackInActivity`, `recipientCategory`, `trackContributions`, `seeYourImpact`, `yourImpact`, `keepItUp`, `chooseOptionToStart`, `aboutApp`, `needHelp`, `needHelpSubtitle`, `addUpdateComment`, `description`, `discardChanges`, `noReports`, `noIdeas`, `noAppreciations`, `savedEmptyTitle`, `suggestImprovement`, `featureImproveSubtitle`, `ideaSuccessMsg`, `ideaSuccessPublicVisible`, `goToMyActivity`, `publicGrievanceHearing`, `activityGreatGoing`, `ideaDetail`, `improvementDetail`, `appreciationDetail`, `statusDescSubmitted`, `statusDescUnderReview`, `statusDescAssigned`, `statusDescInProgress`, `statusDescRejected`)
- Add missing Malayalam strings for keys present in `app_en.arb` but absent from `app_ml.arb` (`seeYourImpact`, `yourImpact`, `keepItUp`, `chooseOptionToStart`, `ideaDetail`, `improvementDetail`, `appreciationDetail`, `statusDescSubmitted`, `statusDescUnderReview`, `statusDescAssigned`, `statusDescInProgress`, `statusDescRejected`, `needHelp`, `needHelpSubtitle`, `addUpdateComment`, `description`)
- **BREAKING** Rename "report/reports" → "issue/issues" throughout English strings where that terminology is used in user-facing labels (`activityTabReports`, `activityFabReport`, `noReports`, `communityImpactReports`, `activityNoReportsWithStatus`, `reportDetail`, `activityEmptyMessage`)
- Apply corresponding Malayalam translations for the renamed keys

## Capabilities

### New Capabilities
- None

### Modified Capabilities
- `report-problem`: Malayalam strings for the report/issue flow corrected and "report" renamed to "issue" in relevant user-facing labels

## Impact

- `lib/l10n/app_ml.arb` — primary file with corrections and additions
- `lib/l10n/app_en.arb` — "report" → "issue" rename in affected user-facing string values
- `lib/l10n/app_localizations_ml.dart` — regenerated by `flutter gen-l10n`
- `lib/l10n/app_localizations_en.dart` — regenerated by `flutter gen-l10n`
- No Dart code changes needed; all changes are in ARB files
